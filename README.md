## Setup Node 24.2.0
Win
- Download: https://github.com/coreybutler/nvm-windows
- `nvm install 24.2.0`
- `nvm use 24.2.0`

Mac
- Install nvm first
- `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash`
- `nvm install 24.2.0`
- `nvm use 24.2.0`
